# hiRecorder
hiRecorder (High-Performance Intel Recorder) is a screen capture tool meant for computers with 11th generation Intel GPUs and higher.
This tool focuses on speed and quality. It was originally made to utilize Intel's GPU hardware decoding options to record video with 4:4:4 subsampling.

### Compatibility
---
This tool currently only works with 11th generation Intel GPUs, see [here](https://github.com/intel/libvpl#dispatcher-behavior-when-targeting-intel-gpus).

### Limitations & Future Features
---
These features are not yet supported and might be added in future updates.
* Multiple monitor support
* Multiple audio/video input support
* Advanced audio/video encoding options
* AI-free code, see [my philosophy](https://github.com/EmilyOrSomething#my-philosophy).
